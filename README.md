# 🏋️ English Drill Bot — тренажёр неправильных глаголов в Telegram

Бот сам пишет тебе задание **2 раза в день в случайное время между 10:00 и 15:00**:

1. **Три формы неправильного глагола** — отвечает на скорость.
2. **2 утвердительных + 2 отрицательных предложения в Past Simple** — проверяет **ИИ** и пишет разбор.

## Баллы

| Ответ на формы | Баллы |
|---|---|
| все 3 формы верные, быстрее **25 секунд** | **25** 🏆 |
| верные, от 25 сек до 1 минуты | **18** |
| верные, дольше минуты | **10** |
| с ошибкой | 0 |

Хороший ответ на предложения (оценивает ИИ): **+10**. Максимум за задание — **35**.

## Файлы

- `bot.py` — логика бота, обработчики команд и ответов, планировщик случайных времён
- `verbs.py` — 69 неправильных глаголов с переводом
- `ai_checker.py` — проверка предложений через ИИ (OpenRouter) + запасная проверка по правилам
- `db.py` — SQLite: статистика, рейтинг, история
- `config.py` — настройки из `.env`

## Установка (Windows)

```bat
cd english-drill-bot
python -m venv .venv
.venv\Scripts\pip install -r requirements.txt
copy .env.example .env
```

## Настройка

1. **Токен бота**: напиши [@BotFather](https://t.me/BotFather) → `/newbot` → вставь токен в `.env` (`BOT_TOKEN=`).
2. **Ключ OpenRouter** (бесплатно): зайди на [openrouter.ai/settings/keys](https://openrouter.ai/settings/keys), создай ключ и вставь в `.env` (`OPENROUTER_API_KEY=`).
3. Модели ИИ уже настроены цепочкой (`OPENROUTER_MODELS` в `.env`): если первая перегружена (у бесплатных моделей общий лимит 429), бот автоматически пробует следующую, а если ИИ недоступен совсем — проверяет по правилам. Свободные на сейчас модели: [openrouter.ai/models?max_price=0](https://openrouter.ai/models?max_price=0).
4. Часовой пояс: если компьютер в твоём поясе, оставь `TIMEZONE=` пустым. Для сервера укажи, например, `TIMEZONE=Europe/Moscow`.

## Запуск

```bat
.venv\Scripts\activate
python bot.py
```

Пиши боту `/start` — он расскажет правила. `/now` — тренировочное задание прямо сейчас.

## Команды

| Команда | Что делает |
|---|---|
| `/start`, `/help` | правила |
| `/now` | тренировочное задание сразу (с баллами) |
| `/skip` | пропустить текущее задание |
| `/stats` | личная статистика: баллы, % верных, среднее время |
| `/top` | рейтинг учеников |

## Как считается время

Таймер стартует в момент, когда бот отправил задание, и останавливается, когда пришло твоё сообщение с формами — так что отвечай одним сообщением. Вторым сообщением присылаются предложения.

## Заметки

- Бот должен работать постоянно, иначе задания в случайное время не отправятся. Два варианта: запущенный на компьютере `python bot.py` **или** бесплатный 24/7 через GitHub Actions (см. ниже).

## 24/7 на GitHub Actions

Репозиторий публичный (для приватных GitHub даёт лишь 2000 минут Actions в месяц — не хватит; для публичных лимита нет). Секреты не публикуются: `BOT_TOKEN` и `OPENROUTER_API_KEY` лежат в зашифрованных Secrets репозитория.

Как это работает:
- каждый день в **09:50 по Москве** GitHub сам запускает job, бот работает до ~**15:10** и покрывает всё окно 10:00–15:00;
- в конце дня job **шифрует** базу (`bot.db` → `bot.db.enc`, AES/Fernet) и коммитит только шифрованный блоб — статистика не теряется, а открытые данные в репозитории не появляются;
- ключ шифрования лежит в секретах GitHub вместе с токенами;
- ручной запуск: вкладка Actions → *daily-drill* → *Run workflow*;
- локальный `python bot.py` при работающем Actions-прогоне запускать нельзя (два бота будут конфликтовать за Telegram).

Если репозиторий месяцам без активностей GitHub может отключить расписание — но ежедневный коммит базы считается активностью, так что этого не случится.

## 🔒 Приватность данных

Какие данные пользователей есть и где они живут:

| Данные | Где хранится | Виден ли в публичном репо |
|---|---|---|
| Telegram ID, ник, имя | база `bot.db` | нет — только в шифрованном `bot.db.enc` |
| Ответы, баллы, разборы ИИ | база `bot.db` | нет — аналогично |
| Токен бота, ключ OpenRouter, ключ шифрования | Secrets GitHub | никогда (в коде и логах их нет) |

Принципы:
- **шифрование**: в репозиторий попадает только `bot.db.enc`; расшифровка происходит лишь на время работы job;
- **минимум в логах**: логи Actions не содержат ID пользователей и их ответов;
- **право на удаление**: любой ученик может отправить боту `/forget ДА` — все его записи стираются из базы безвозвратно;
- не пиши в ответы боту личные данные (адреса, телефоны) — ответы хранятся в базе как часть статистики.
